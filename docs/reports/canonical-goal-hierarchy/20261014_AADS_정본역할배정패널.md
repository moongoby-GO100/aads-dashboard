## 3. 대표님 버튼 순서

0. `/goals` 에서 대상 목표를 열고 "정본 역할 배정" 패널을 엽니다(기준값이 있는 목표는 기본 펼침).
1. **현황 확인** — 읽기 전용. 현재 Epic/Story/Task 건수와 배정 연결 건수.
2. **승인 참조 입력** — `[CEO] 통합지시` 창 주소(또는 세션 ID), 결정 참조(handover entry_key), 승인 원 메시지 ID. 서버는 이 창의 소유자가 로그인 사용자인지 검증합니다.
3. **목표 전용 세션 준비** — 없는 PM·Developer·QA 세션이 있으면 "없는 세션 N개 생성" → 확인 창 → 생성. 이미 있으면 재사용하고 생성 직전에 목록을 다시 조회해 중복 생성을 막습니다.
4. **미리보기** — 서버 계산 결과를 표로 확인(역할별 Epic/Story/Task/합계, ID 집합 md5, 승인 증거, 보유 세션). 기준(PM36·Developer30·QA24, 총 90, md5 `c523a6d044c5d0be31f3469161a66beb`)과 다르면 경고 배너가 뜨고 이후 단계 버튼이 비활성화됩니다.
5. **제안** → **승인**(확인 창: 대상·건수·되돌리는 방법 표시) → **실행**(확인 창, 고정 실행 키 `canonical-assign-exec:<변경세트 ID>`, 연타 방지). 실행 후 전·후 배정 건수 표가 나옵니다.
6. **롤백** — 실행된 변경 세트가 있을 때만 버튼이 보이고, 사유 입력 + 확인 창 뒤에 실행됩니다(롤백 키 `canonical-assign-rollback:<변경세트 ID>`).

미리보기보다 세션 준비가 앞서는 이유: 서버 미리보기가 보유 세션 UUID 3개를 입력으로 요구하기 때문입니다(지시서의 "미리보기 → 세션 생성" 순서에서 벗어난 부분). 세션 준비 전에는 작업 트리 기반의 읽기 전용 현황만 표시합니다.
