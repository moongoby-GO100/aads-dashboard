# WP02 RESULT — 단일 채팅 viewport controller

작성 기준일은 2026-09-12이며, 이 문서는 [검증·롤아웃 계획의 WP02](../VERIFICATION-AND-ROLLOUT.md)에 대한 구현 기록이다. 최종 기준은 WP01 보안·receipt hardening과 검증 기록이 포함된 `origin/main`의 `5f6b0d7d80ee4f1e9840134036003575ea125d6a`다.

## 검증

- `npm run typecheck`: 통과.
- `npm run test:chat`: 23/23 통과. WP00의 기존 20건에 WP02 controller/architecture/purity 3건을 추가했다.
- `npm run lint:chat`: 신규 오류/경고 없이 기존 경고 상한 23건으로 통과하도록 확인한다.
- 정적 writer 검사: `src/app/chat/page.tsx`의 `scrollTop=`·`scrollIntoView`·`scrollTo`·`scrollBy` 0건. 실제 쓰기는 adapter만 가진다.

## 남은 gate

Playwright Chromium/Firefox/WebKit의 실제 layout, 이미지·폰트 지연 후 ±2 CSS px, trackpad momentum, touch, native scrollbar drag, A→B→A, version reload는 아직 실행하지 않았다. 따라서 이 커밋은 deterministic selftest와 source architecture gate를 제공하지만 T01~T04의 브라우저 인수를 완료했다고 주장하지 않는다. 운영 push·배포·feature flag 전환도 이 격리 작업 범위에서 수행하지 않는다.

## 롤백

이 커밋의 viewport module·route bridge·WP02 test/document/HANDOVER 항목만 되돌리면 기준 브랜치의 v1 scroll 경로로 복귀한다. DB/API/schema 변경은 없다.
