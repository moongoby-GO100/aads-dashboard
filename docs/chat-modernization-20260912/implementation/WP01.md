# WP01 RESULT — 실행 환경 게이트와 생성 HTML 안전 경계

작성 기준일은 2026-09-13이다. 이 문서는 [검증·롤아웃 계획의 WP01](../VERIFICATION-AND-ROLLOUT.md)에 대한 구현 기록이다.

## 변경 범위

- Node 24 기반 빌드 환경과 실패 폐쇄형 TypeScript/React Compiler 게이트를 추가했다.
- Markdown 및 생성 HTML은 공통 정책 모듈을 통과하게 했다.
- 생성 HTML은 부모 문서가 소유한 CSP 안에서 opaque sandbox iframe으로 격리하며 `allow-scripts`를 부여하지 않는다.
- 새 창 미리보기 또한 원문 Blob을 직접 열지 않고 같은 정적 격리 정책을 사용한다.
- Server interrupt receipt는 메시지 INSERT와 세션 counter UPDATE를 한 transaction으로 묶고, 영속화가 확인되지 않으면 HTTP 503으로 실패 폐쇄한다.

## 보안 경계

공격자가 제공한 HTML 안에 fake/commented `head`, 선행 활성 요소 또는 CSP처럼 보이는 문자열이 있어도 신뢰하지 않는다. 외부 wrapper가 처음부터 `default-src 'none'` 정책을 소유하고, 원문은 escape한 뒤 sandboxed child document의 `srcdoc` 값으로만 전달한다. Markdown HTML code fence와 artifact preview는 동일 함수를 사용한다.
