## 측정 기준선

Node `v20.20.2`에서 고정 시각·고정 UUID로 생성한 fixture 결과다.

실제 `mergeServerMessagesPreservingLocal`을 5회 실행한 최종 검증 표본은 40행 `12.189/5.831/5.892/5.785/4.474 ms`(관측 p95 `12.189 ms`), 150행 `109.786/66.903/65.094/55.636/50.515 ms`(관측 p95 `109.786 ms`)였다. 재실행 wall-clock 값은 머신 부하에 따라 달라지므로 fixture hash와 행 보존만 pass/fail 계약이고 시간은 회귀 비교용 관측치다. 브라우저 UX 합격 기준으로 사용하지 않는다.

네 기존 SSE reader 모두 정상 3 event와 CRLF 1 event, 모든 UTF-8 단일 byte split, reader 내부 중복 ID 제거를 통과했다. 동시에 현재의 공통 미해결 동작도 fixture로 기록했다: multi-line `data:` frame과 `data:` 뒤 공백이 없는 frame은 전달하지 않고, 빈 줄로 닫히지 않은 마지막 frame은 1건 전달하며, 잘못된 JSON 뒤 cursor가 진행한다. WP00에서는 이 관측을 원하는 규격으로 오인해 제품 parser를 고치지 않는다. 실제 수정 판정은 후속 WP의 ADR/T gate를 따른다.

## 검증 결과와 미확인 항목

- Dashboard Node 회귀: 20/20 통과. 기존 scroll 12건과 replacement 10건도 실제 파일에서 함께 통과했다.
- Dashboard 전체 TypeScript typecheck는 기준 SHA 소스와 검증된 lockfile 의존성으로 통과했다. Scoped ESLint는 신규 오류 0건, 기존 `page.tsx` warning 19건으로 설정한 상한과 일치해 통과했다.
- Server 관련 회귀: 43/43 통과. FastAPI의 기존 `Query(regex=...)` deprecation warning 1건은 본 범위의 실패가 아니다.
- Server 신규 테스트 Ruff: 통과.
- 문서 verifier는 이 구현 문서까지 ID·상대 링크·heading·code fence를 검사하도록 확장했고, 7문서·80링크·219 ID·44 FR-to-test mapping을 통과했다. AADS workspace에서는 cross-repository 링크 18개도 실제 파일로 확인하며, 단독 Dashboard checkout에서는 정확히 선언한 cross-repository 대상만 별도 집계한다.
- CI는 `continue-on-error` 없이 Dashboard typecheck → scoped lint → 회귀 → 기준선 → 문서 검증 순서를 고정한다. Server CI는 `pytest-timeout`을 dev dependency에 명시하고 OAuth token 우선 환경에서 WP00 관련 회귀를 전체 unit 단계보다 먼저 실행한다.

아직 수치로 확인하지 않은 항목은 실제 Chromium/WebKit/Firefox layout·RAF·gesture, 데스크톱/모바일 물리 장치, route 전체 INP·heap·장시간 스트림, IME/키보드/스크린리더, 실제 DB/Redis/provider 및 다중 worker 경쟁이다. [matrix.json](../../../tests/chat-modernization/matrix.json)은 이 항목을 `not-run`으로 명시해 자동 통과로 취급하지 않는다. 시스템 Python의 최초 수집은 FastAPI/asyncpg 미설치 때문에 실패했으며, 저장소의 격리 venv로 위 43개를 실행해 하네스 자체를 확인했다. 격리 Dashboard의 `npm ci --ignore-scripts`는 이 환경의 registry DNS 제한(`EAI_AGAIN`)과 npm 종료 처리 오류 때문에 완료되지 않았으므로 clean-install 실행 자체는 미확인이다. 소스 typecheck·lint·test는 기존의 동일 프로젝트 의존성 트리로 각각 독립 실행했다.

## 재현과 롤백

깨끗한 Dashboard checkout에서는 `npm ci --ignore-scripts`, `npm run typecheck`, `npm run lint:chat`, `npm run test:chat`, `npm run test:chat:baseline`, `npm run test:chat:docs` 순서로 재현한다. Server는 dev dependency 설치 후 CI에 기록된 네 pytest 파일을 동일 환경 변수 계약으로 실행한다. 합성 credential만 사용하며 외부 LLM·DB·Redis·network 호출은 없다.

롤백은 Dashboard의 신규 `tests/chat-modernization/`, workflow, package script와 본 문서/verifier/HANDOVER 항목 및 Server의 신규 테스트, CI 단계, timeout dev dependency, HANDOVER 항목만 되돌리면 된다. 제품 소스·DB schema·저장 데이터는 변경하지 않았으므로 별도 데이터 롤백은 없다.
